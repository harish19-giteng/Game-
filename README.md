# Guess The Number Game 🎮

A simple interactive number guessing game built with HTML, CSS, and JavaScript.

## Features
✅ Guess a random number between 1-100
✅ Get hints if your guess is too high or too low
✅ Track your attempts
✅ Leaderboard with best scores (saved locally)
✅ Responsive design (works on mobile & desktop)
✅ No dependencies needed

## How to Play
1. The game thinks of a number between 1 and 100
2. You have to guess it
3. The game tells you if your guess is too high or too low
4. Keep guessing until you find the number
5. Try to do it in as few attempts as possible!

## Files
- `index.html` - Game structure
- `style.css` - Game styling
- `script.js` - Game logic
- `README.md` - This file

## How to Deploy

### Option 1: Vercel
1. Create a GitHub repository
2. Push this code to GitHub
3. Go to vercel.com and connect your GitHub account
4. Import this repository
5. Click Deploy
6. Your game is live! 🚀

### Option 2: Netlify
1. Create a GitHub repository
2. Push this code to GitHub
3. Go to netlify.com and connect your GitHub account
4. Click "New site from Git"
5. Select your repository
6. Click Deploy
7. Your game is live! 🚀

## Technologies Used
- HTML5
- CSS3 (Flexbox, Gradients, Animations)
- Vanilla JavaScript (ES6+)
- LocalStorage for saving scores

Works on all modern browsers (Chrome, Firefox, Safari, Edge)
